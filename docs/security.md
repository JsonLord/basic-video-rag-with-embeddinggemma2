# Security and privacy

The intended deployment is a private, single-user Space. Set visibility in Hugging Face settings; README frontmatter does not make a Space private. Keep HTTPS enabled. Library/media inherit Space privacy. Inference/session APIs also require VM_USER_TOKEN and configuration/synthetic-test APIs require VM_ADMIN_TOKEN, each at least 24 random characters. Supply distinct values as Space Secrets. The current token principal is single-user: do not share VM_USER_TOKEN across mutually untrusted users; add individual authentication before multi-user deployment. Session ownership is checked against the authenticated principal.

The browser keeps entered tokens in sessionStorage, not URLs, YAML, cookies or server logs. Treat this as tab-scoped login; close the tab to clear it. Bearer authentication avoids ambient-cookie CSRF, and browser Origin checks reject unrelated origins. `VM_ALLOWED_ORIGINS` may explicitly list approved application origins. Behind the bundled loopback proxy, forwarded host is accepted only from loopback. Do not expose FastAPI directly or put an untrusted reverse proxy on that boundary.

YAML uses SafeLoader, unique keys, a strict Pydantic schema, 64 KiB limit, and rejects anchors/aliases and extra fields. No commands, file paths or inline credentials are accepted. Validation errors omit input values. Exports contain credential reference names only. API errors and provider telemetry expose categories and durations, never provider response bodies or keys. Do not paste credentials into free-text model/label fields.

Destinations must resolve to public IPs, use HTTPS:443, omit userinfo/query/fragment, and exactly match administrator `VM_ALLOWED_HOSTS`; environment-variable endpoints cannot be overridden by YAML. Redirects are disabled. Sensitive calls additionally require approved_sensitive for each provider. TLS validation stays enabled. Hosts in this allowlist are a trust boundary: use provider-controlled stable DNS and enforce network egress denial of private/metadata destinations in the hosting infrastructure too (including at proxy DNS resolution), to prevent DNS rebinding between application validation and connection. This application does not configure the hosting network firewall. Do not approve attacker-controlled DNS.

Request bodies are capped at 3 MiB with 16 concurrent requests; images at 1.5M base64 characters, 1920×1080, JPEG/WebP; provider responses at 2 MiB. Session frames are rate-limited and stale IDs rejected. There are at most 32 sessions, four per principal, 30-minute expiry, and 20 in-memory observation records per session. Audio clips are browser-limited to 15 seconds and 2 MB WebM; the server checks container magic/size and declared duration, without decoding audio locally. A hostile authorized client can misreport duration; use the provider's enforced duration quota as well.

Existing video RAG answer history is retained under VRAG_DATA/answers by default; set VRAG_SAVE_ANSWERS=false to disable new answer persistence. This history contains answers/citations, not camera uploads.

No raw camera frames/audio are written to disk. An analyzed still stays in the browser until clear/stop/navigation, and semantic observations remain in process memory until clear/expiry. Previews stop on hidden tab, track end, stop or teardown. Session deletion discards in-flight results. Closing a connection cancels requests once disconnect is observed; upstream providers may have already processed submitted data. Camera/microphone activation never happens automatically. Do not enable provider-side retention unless explicitly intended.

Configuration defaults are read-only without VM_STATE_DIR. Configured history uses atomic replacement with file fsync, optimistic version checks and a maximum of 100 versions. Mount persistent storage if history must survive Space rebuilds; a directory name alone does not guarantee persistence. Sessions always remain ephemeral. Back up configuration history before changing storage; keep indexes/media on explicit protected storage. There is no autonomous mentoring or background research execution.
